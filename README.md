## 🕹️ About

Happy Wheels is a 2D side-scrolling, physics-based obstacle-course game created by Jim Bonacci and published by Fancy Force. Players choose from unusual racers and vehicles, then navigate dangerous courses filled with spikes, traps, explosives, and unpredictable physics. Its community-driven level system adds a huge variety of player-created challenges, while ragdoll movement and dark cartoon humor make every attempt memorable.

Happy Wheels is made for players who enjoy inventive obstacle courses, comedic physics, challenging retries, and user-created content.

## ✨ Features

- 💥 **Physics-Based Gameplay** — Use momentum, balance, and timing while reacting to unpredictable ragdoll physics.
- 🎭 **Dark Cartoon Humor** — Combine exaggerated character reactions with satirical cartoon violence.
- 🌐 **Community Levels** — Explore a constantly evolving library of inventive player-created challenges.
- 🏁 **Obstacle Courses** — Race through hazardous levels packed with traps, hazards, and precision challenges.
- 🧰 **Level Editor** — Create custom courses using tools, objects, hazards, and interactive elements.
- 🛞 **Distinct Racers** — Choose from characters with different vehicles, abilities, and handling styles.
